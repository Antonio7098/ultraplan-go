## Summary

LangGraph treats interop boundaries as **core abstractions**, not afterthoughts. `PregelProtocol`, `BaseChannel`, `BaseCheckpointSaver`, `BaseStore`/`BaseCache`, and `SerializerProtocol`/`ChannelProtocol` are abstract interfaces defined in `libs/checkpoint` and `libs/langgraph` that core (`Pregel`, `PregelLoop`, `channels_from_checkpoint`, stream mux) depends on via dependency inversion. Concrete adapters (`InMemorySaver`, `InMemoryStore`, `JsonPlusSerializer`, `DeltaChannel`/`LastValue`/`Topic`, `PostgresSaver`/`SqliteSaver` in sibling packages) live in separate packages and are injected at runtime via constructor/config (`Pregel(checkpointer=...)`, `store=`, `cache=`, `serde=`). Adding a new checkpointer, store, channel, or serializer requires subclassing the base protocol and passing the instance — no core patches.

The checkpoint boundary is **mature**: a dedicated `langgraph-checkpoint-conformance` library auto-detects capabilities and runs ~9 spec suites (`put`/`get_tuple`/`list`/`put_writes`/`delete_thread` + optional `copy_thread`/`prune`/`delete_for_runs`/`delta_channel_history`). Store/Cache/Channel/Serde boundaries have explicit `ABC`/`Protocol` contracts and reference implementations but lack an equivalent conformance harness. Streaming (`StreamProtocol`, `StreamTransformer`) and `DeltaChannel` are beta with evolving contracts and documented caveats about ancestor-chain reconstruction. Documentation is thorough at the API-docstring level but lacks a single interop-architecture guide.

## Rating

**7 / 10 — Clear model with tests, explicit interfaces, and operational safeguards, but uneven coverage and beta instability prevent a durable/mature rating.**

Rationale: All major protocols are core abstractions with swappable adapters (checkpoint, store, cache, serde, channel, stream). Checkpoint adapters have a production-grade conformance framework with capability detection and isolated spec tests. Runtime swappability is proven via DI in `Pregel` and `InMemorySaver/Store`. Gaps: no conformance suite for `BaseStore`/`BaseCache`/`BaseChannel`/`SerializerProtocol`; `DeltaChannel` history/prune/copy invariants are fragile (silent reconstruction failure if adapter drops ancestors); interop extension points are documented via docstrings/README tables, not a centralized boundary spec. No chaos/failure injection tests observed.

## Answers to Dimension Questions

**1. Are protocols core or adapter-layer?**
Core. `PregelProtocol`/`StreamProtocol` (`libs/langgraph/langgraph/pregel/protocol.py:25`), `BaseChannel` (`libs/langgraph/langgraph/channels/base.py:19`), `BaseCheckpointSaver` (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:176`), `BaseStore` (`libs/checkpoint/langgraph/store/base/__init__.py:708`), `BaseCache` (`libs/checkpoint/langgraph/cache/base/__init__.py:15`), `SerializerProtocol`/`ChannelProtocol` (`libs/checkpoint/langgraph/checkpoint/serde/base.py:6`, `libs/checkpoint/langgraph/checkpoint/serde/types.py:39`) are ABC/Protocol abstractions that `Pregel`, `PregelLoop` (`libs/langgraph/langgraph/pregel/_loop.py:167-184`), and `channels_from_checkpoint` (`libs/langgraph/langgraph/pregel/_checkpoint.py:229-319`) depend on. Adapters (`InMemorySaver` `libs/checkpoint/langgraph/checkpoint/memory/__init__.py:33`, `InMemoryStore` `libs/checkpoint/langgraph/store/memory/__init__.py:136`, `JsonPlusSerializer` `libs/checkpoint/langgraph/checkpoint/serde/jsonplus.py:82`, `DeltaChannel` `libs/langgraph/langgraph/channels/delta.py:25`, Postgres/SQLite savers in `libs/checkpoint-postgres`, `libs/checkpoint-sqlite`) are leaf packages. Monorepo dependency map confirms `checkpoint` is upstream of all (`AGENTS.md`). Standards are not afterthought integrations.

**2. Can adapters be added without core changes?**
Yes. All boundaries support open extension via subclassing + DI:
- **Checkpointer**: subclass `BaseCheckpointSaver`, implement `get_tuple`/`put`/`list`/`put_writes`/`delete_thread` (+ optional `aget_*`/`copy_thread`/`prune`/`get_delta_channel_history`), pass to `Pregel(checkpointer=saver)` (`libs/langgraph/langgraph/pregel/main.py:798-818`) or via `RunnableConfig["configurable"]["thread_id"]`/`CONFIG_KEY_CHECKPOINTER` (`libs/langgraph/langgraph/pregel/main.py:1396-1400`). `ensure_valid_checkpointer` only checks `isinstance(... BaseCheckpointSaver)` (`libs/langgraph/langgraph/types.py:109-119`).
- **Store/Cache**: implement `BaseStore.batch`/`abatch` or `BaseCache.get`/`set` and inject as `store=`/`cache=` (`libs/langgraph/langgraph/pregel/main.py:737-738`).
- **Serde**: implement `SerializerProtocol.dumps_typed`/`loads_typed` and pass as `BaseCheckpointSaver(serde=my_serde)` (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:210-216`); `maybe_add_typed_methods` wraps legacy `dumps`/`loads` (`libs/checkpoint/langgraph/checkpoint/serde/base.py:40-48`).
- **Channel**: subclass `BaseChannel`, register in `Pregel(channels={...})` (`libs/langgraph/langgraph/channels/base.py:19-121`); `DeltaChannel` demonstrates zero core edits beyond `create_checkpoint` snapshot set (`libs/langgraph/langgraph/pregel/_checkpoint.py:149-214`).
- **Stream**: provide `StreamTransformer` factories via `Pregel(stream_transformers=[MyTransformer])` (`libs/langgraph/langgraph/pregel/main.py:783-447`) with auto-forwarding in `StreamMux` (`libs/langgraph/langgraph/stream/_mux.py:470`).
No registry mutation or core file edit is required; `_apply_checkpointer_allowlist` even clones saver to extend msgpack allowlist without mutation (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:713-722`).

**3. Are adapters tested for conformance?**
Partially — checkpoint boundary is mature, others are not.
- **Checkpoint**: dedicated `langgraph-checkpoint-conformance` library. Capabilities enum (`libs/checkpoint-conformance/langgraph/checkpoint/conformance/capabilities.py:15-26`), auto-detection via `__dict__` override check (`libs/checkpoint-conformance/langgraph/checkpoint/conformance/capabilities.py:90-96`), and `validate()` runner dispatching to 9 spec modules (`libs/checkpoint-conformance/langgraph/checkpoint/conformance/validate.py:32-42`). Each spec (`test_put.py` `test_put_writes.py` `test_get_tuple.py` `test_list.py` `test_delete_thread.py` `test_copy_thread.py` `test_delete_for_runs.py` `test_prune.py` `test_delta_channel_history.py`) contains 3-15 async tests exercising blob round-trip, namespace isolation, metadata preservation, incremental updates, and `DeltaChannel` ancestor walks. README documents base vs extended table and usage (`libs/checkpoint-conformance/README.md:64-80`). Postgres/SQLite/InMemory savers are expected consumers.
- **Store/Cache/Channel/Serde/Stream**: Explicit `ABC`/`Protocol` contracts exist but **no conformance harness** was found. `libs/checkpoint/tests/test_jsonplus.py` and `libs/checkpoint/tests/test_encrypted.py` provide unit tests for serde, not a pluggable suite. `InMemoryStore`/`InMemorySaver` serve as reference impls but no `store-conformance` package exists.
Thus conformance is strong for the primary persistence boundary, weak elsewhere.

**4. Are interop boundaries documented?**
Docstring/RM-level yes, architecture-guide no.
- Each base class carries extensive docstrings: `BaseCheckpointSaver` thread semantics and `DeltaChannel` prune/copy warnings (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:176-414`), `BaseStore` hierarchical namespace + `TTLConfig`/`IndexConfig` (`libs/checkpoint/langgraph/store/base/__init__.py:1-706`), `BaseCache` (`libs/checkpoint/langgraph/cache/base/__init__.py:15-48`), `JsonPlusSerializer` security note (`libs/checkpoint/langgraph/checkpoint/serde/jsonplus.py:82-95`), `DeltaChannel` reducer invariants (`libs/langgraph/langgraph/channels/delta.py:25-64`).
- `libs/checkpoint-conformance/README.md:19-124` acts as the canonical interop spec for checkpoint: capability table, `validate` API, `skip_capabilities`, `lifespan`, `progress` callbacks.
- `libs/checkpoint/README.md:47` notes serde protocol and default `JsonPlusSerializer`.
- `PregelProtocol` methods are self-documenting via signatures (`libs/langgraph/langgraph/pregel/protocol.py:25-288`), but there is no cross-boundary architecture doc tying `Pregel ↔ Checkpoint ↔ Store ↔ Cache ↔ Serde ↔ Channel ↔ Stream` together, nor a guide for `DeltaChannel` `snapshot_frequency` tuning or safe `prune` implementation. `AGENTS.md` dependency map is the closest high-level view.

## Architectural Decisions

- **Monorepo with leaf adapters, core interfaces upstream.** `checkpoint` package owns `BaseCheckpointSaver`/`BaseStore`/`BaseCache`/`SerializerProtocol`; `langgraph` depends on it, `checkpoint-postgres`/`checkpoint-sqlite` depend downstream. Prevents core from importing adapters. Evidence: `libs/langgraph/pyproject.toml:28-29` declares `langgraph-checkpoint>=4.1.0`; `AGENTS.md` diagram shows `checkpoint → langgraph, prebuilt, checkpoint-postgres, checkpoint-sqlite`.
- **Abstract base over Protocol for persistence, Protocol for serde/stream.** `BaseCheckpointSaver`/`BaseStore`/`BaseCache`/`BaseChannel` are `ABC` with default `NotImplementedError` impls enabling gradual optional-method adoption (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:248-580`); `SerializerProtocol`/`ChannelProtocol`/`SendProtocol` are `Protocol`+`runtime_checkable` for structural typing (`libs/checkpoint/langgraph/checkpoint/serde/base.py:14`, `libs/checkpoint/langgraph/checkpoint/serde/types.py:39-68`).
- **Sync + async dual surface with default cross-calling.** Every `get`/`put`/`list` has `aget`/`aput`/`alist`; `InMemorySaver` implements async by delegating to sync (`libs/checkpoint/langgraph/checkpoint/memory/__init__.py:523-611`). `PregelLoop` branches on presence of checkpointer (`libs/langgraph/langgraph/pregel/_loop.py:1517-1529`).
- **Capability detection via override inspection.** `DetectedCapabilities.from_instance` iterates `_CAPABILITY_METHOD_MAP` and checks `impl is not base` (`libs/checkpoint-conformance/langgraph/checkpoint/conformance/capabilities.py:74-96`). Enables optional `copy_thread`/`prune`/`delta_channel_history` without versioned interfaces.
- **DeltaChannel sentinel + ancestor walk.** `DeltaChannel.checkpoint()` always returns `MISSING` (`libs/langgraph/langgraph/channels/delta.py:193-202`); `create_checkpoint` writes `_DeltaSnapshot` only at cadence (`libs/langgraph/langgraph/pregel/_checkpoint.py:180-202`); `channels_from_checkpoint` batches one `get_delta_channel_history` call per step (`libs/langgraph/langgraph/pregel/_checkpoint.py:254-263`). Bounds storage but couples adapter correctness to `get_delta_channel_history` contract.
- **Serde security via allowlist cloning, not mutation.** `with_allowlist` returns a shallow copy with merged `JsonPlusSerializer` (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:713-722`, `libs/checkpoint/langgraph/checkpoint/serde/jsonplus.py:128-158`); `Pregel._apply_checkpointer_allowlist` uses `_serde.apply_checkpointer_allowlist` iff `STRICT_MSGPACK_ENABLED` (`libs/langgraph/langgraph/pregel/main.py:838-843`). Avoids global state.
- **Channel versions as monotonic strings with random suffix.** `InMemorySaver.get_next_version` returns `f"{next_v:032}.{random}"` (`libs/checkpoint/langgraph/checkpoint/memory/__init__.py:613-622`) vs base integer increment (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:692-711`) — allows pluggable version scheme per saver.

## Notable Patterns

- **Dependency inversion at loop boundary.** `PregelLoop` stores `checkpointer_get_next_version: Callable`, `checkpointer_put_writes: Callable`, `checkpointer_put_after_previous` instead of the saver itself (`libs/langgraph/langgraph/pregel/_loop.py:182-185`), enabling `None` sentinel for no-checkpointer runs and inspection of `signature(put_writes)` for `task_path` arity (`libs/langgraph/langgraph/pregel/_loop.py:1520-1521`).
- **Decorator-registered conformance factories.** `@checkpointer_test(name=..., lifespan=...)` appends `RegisteredCheckpointer` to `_REGISTRY` (`libs/checkpoint-conformance/langgraph/checkpoint/conformance/initializer.py:59-99`); `validate` enters `lifespan` once and `create()` per capability (`libs/checkpoint-conformance/langgraph/checkpoint/conformance/validate.py:74-78`).
- **Batch-oriented Store API.** `BaseStore.batch(Iterable[Op]) -> list[Result]` coalesces `GetOp`/`SearchOp`/`PutOp`/`ListNamespacesOp` (`libs/checkpoint/langgraph/store/base/__init__.py:733-754`) with deduplication in `AsyncBatchedBaseStore` (`libs/checkpoint/langgraph/store/base/batch.py:283-323`) — single RPC for cross-namespace transactions.
- **Typed serde envelope.** `dumps_typed -> (type_str, bytes)` where first element is `"msgpack" | "json" | "pickle" | "bytes" | "null"` (`libs/checkpoint/langgraph/checkpoint/serde/jsonplus.py:258-290`), preserved in `InMemorySaver.storage` as `(serde.dumps_typed(checkpoint), serde.dumps_typed(metadata), parent_id)` (`libs/checkpoint/langgraph/checkpoint/memory/__init__.py:450-457`).
- **Scoped stream transformer factories.** `Pregel(stream_transformers=[lambda scope: MyTransformer(scope)])` rejected if pre-built instance (`libs/langgraph/langgraph/pregel/main.py:430-436`) so subgraphs get scoped muxes.

## Tradeoffs

- **Explicit ABC raises barrier but avoids drift.** Requiring subclasses to override `get_tuple`/`put`/`list` etc. guarantees contract, but adapters that only support a subset must still raise `NotImplementedError` on unsupported extended methods; detection via `is not base` is brittle to intermediate subclasses that wrap without overriding the exact `aget_*` name.
- **DeltaChannel optimizes write amplification at cost of read complexity.** Storing `MISSING` + walking ancestors reduces blob size 1000× (snapshot every 1000 updates, `libs/langgraph/langgraph/channels/delta.py:74`, `libs/langgraph/langgraph/pregel/_checkpoint.py:50-72`) but makes every `get_state`/`channels_from_checkpoint` pay an ancestor walk (`libs/langgraph/langgraph/pregel/_checkpoint.py:260-273`) and makes naive `prune`/`delete_for_runs` silently corrupt state — mitigated only by doc warnings (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:340-414`), not runtime checks.
- **Permissive deserialization by default trades UX for security.** `STRICT_MSGPACK_ENABLED` defaults to `False` (`libs/checkpoint/langgraph/checkpoint/serde/_msgpack.py:12-16`) and `JsonPlusSerializer` warns-but-allows unknown types (`libs/checkpoint/langgraph/checkpoint/serde/jsonplus.py:565-586`). Prevents breaking existing checkpoints but requires `LANGGRAPH_STRICT_MSGPACK=true` + `with_allowlist` for hardened deployments, adding ops burden.
- **Conformance depth vs breadth.** Investing in a full checkpoint conformance harness yields high confidence for persistence, but lack of equivalent for `BaseStore`/`BaseCache`/`SerializerProtocol` means third-party vector-store or cache adapters have no contract test, risking semantic search or TTL drift across implementations (e.g., `InMemoryStore._cosine_similarity` pure-Python fallback `libs/checkpoint/langgraph/store/memory/__init__.py:493-522` vs postgres pgvector).
- **Monorepo coupling.** Shared `libs/checkpoint` types avoid duplication but mean breaking changes to `BaseCheckpointSaver` (e.g., new `get_delta_channel_history`) require coordinated bumps across `checkpoint-postgres`/`checkpoint-sqlite`/`langgraph`; `pyproject.toml` pins `>=4.1.0,<5.0.0` (`libs/langgraph/pyproject.toml:28`) signal semver discipline.

## Failure Modes / Edge Cases

- **Silent delta reconstruction as empty.** `BaseCheckpointSaver.get_delta_channel_history` default walks `get_tuple`+`parent_config` (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:582-649`); if a saver’s `prune("keep_latest")` drops intermediate checkpoints + `checkpoint_writes` between kept head and nearest `_DeltaSnapshot`, walk terminates early and `_needs_replay` → `from_checkpoint(MISSING)` yields empty `typ()` (`libs/langgraph/langgraph/channels/delta.py:131-132`) with no error. Warnings explicitly call this “silently reconstruct as empty” (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:395-413`).
- **Version collision on concurrent put.** `get_next_version` default uses integer increment (`libs/checkpoint/langgraph/checkpoint/base/__init__.py:692-711`) while `InMemorySaver` uses `f"{n:032}.{random}"` (`libs/checkpoint/langgraph/checkpoint/memory/__init__.py:613-622`); adapters that rely on timestamp ordering but use `uuid6(clock_seq=step)` (`libs/checkpoint/langgraph/checkpoint/base/id.py:79-109`, `libs/langgraph/langgraph/pregel/_checkpoint.py:209`) risk clock skew issues — not tested under concurrency.
- **Serde allowlist bypass via fallback.** `JsonPlusSerializer` falls back to `pickle` if `pickle_fallback=True` and msgpack encoding fails (`libs/checkpoint/langgraph/checkpoint/serde/jsonplus.py:268-271`); if `InMemorySaver.factory` injects a dict subclass with shared `writes` (`libs/checkpoint/langgraph/checkpoint/memory/__init__.py:85-99`), pickled payloads could execute code on `loads_typed` when strict mode is off.

QA to repair workflow

Product code owns admission, evidence checks, adjudication, patch validation, production apply, and verdicts. Models investigate and propose. They do not grant themselves commands or mutation scope.

  1. Admissioncurrent inputs and authority
  2. QA mapdeterministic shards
  3. Investigateread-only model work
  4. Evidenceapproved isolated checks
  5. Synthesisdedupe and interactions
  6. Adjudicatepromote eligible issues
  7. Assignordered worker queues
  8. Repairone issue per run
  9. Verifyscoped then containing
  10. Terminaldurable campaign result

What broke, and what changed

  1. agentwrap cc51e26

    Usage fields were empty

    The OpenCode projector expected the wrong usage shape. The update restored input, output, cache, timing, and cost propagation.

  2. 324b4a97

    Equivalent findings duplicated

    Synthesis and adjudication now deduplicate by normalized claim, issue class, and location. Evidence is unioned and the strongest severity survives.

  3. 324b4a97

    Evidence identity checks compared the wrong facts

    The implementation and bounded-tree comparisons now use independently observed identities.

  4. ffac3594

    A grouped queue could not finish truthfully

    The repair protocol gained an explicit pending outcome, a deferred smoke gate, stable worker paths, safe next-packet rebasing, and a mandatory final global gate.

  5. 4caf1c34

    “Campaign” had no formal definition

    Architecture, CLI, user, and configuration docs now distinguish assignment, repair run, and campaign.

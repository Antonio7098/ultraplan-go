# Create Sprint Code Context

Explore the resolved implementation repository in depth, guided by the validated sprint requirements. Produce one concise, durable Markdown context pack containing exact source excerpts that will help later agents reason about and plan the sprint.

Inspect enough implementation, boundary, configuration, error-handling, and test code to understand the current behavior before selecting excerpts. Include useful surrounding context and explain why each excerpt matters.

Return only the complete `code-context.md` Markdown document. Do not make source or Git changes, write any other artifact, propose a final design, or produce an implementation plan.
